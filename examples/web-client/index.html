1. System Architecture & Topology

Wavia Voice AI separates control, real-time voice streaming, and carrier telephony into three specialized high-performance microservices:

Control Plane API (Port 8000)

FastAPI service handling tenant JWT minting, RBAC, agent configuration, secrets, RAG knowledge bases, and static docs.

Worker Raw Real-Time Audio Node (Port 8081)

High-throughput sovereign WebSocket node running Silero VAD, STT streaming, LLM token chunking, and TTS audio synthesis.

Telephony Carrier Gateway (Port 8083)

Carrier PSTN / SIP trunk bridge normalizer for Telnyx & Twilio media streams with mu-law audio transcoding.

2. Startup Commands & Quickstart

Run these commands in separate terminal windows from the repository root:

TERMINAL 1: START CONTROL PLANE
.venv\Scripts\python.exe -m uvicorn control_plane.app:app --port 8000
TERMINAL 2: START WORKER RAW AUDIO NODE
.venv\Scripts\python.exe -m uvicorn worker_raw.main:app --port 8081
TERMINAL 3: START TELEPHONY GATEWAY
.venv\Scripts\python.exe -m uvicorn telephony_gateway.main:app --port 8083

Speculative RAG Architecture

To achieve zero latency impact during conversation, Wavia uses a 2-stage speculative retrieval pipeline:

1. Speculative Partial Fetch

As the user is still talking, partial transcripts from Gladia STT trigger a background asynchronous vector query.

2. Final Reconcile & Prompt Injection

When VAD detects silence and final transcript arrives, Levenshtein distance reconciles the query. Relevant chunks are injected into prompt before LLM first token.
